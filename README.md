# SISTEMA DE SUPERMERCADO: Plataforma Inteligente para Análisis, Predicción y Opiniones de Clientes 
PROBLEMATICA:
Una empresa tiene información histórica de sus ventas, productos, clientes y opiniones. 
Actualmente registra los datos, pero no sabe qué productos venderán más, qué clientes 
tienen mayor probabilidad de abandonar, cuáles son las opiniones positivas o negativas y 
qué patrones existen en sus ventas.
